## machine Description

BloodFlow is a Very Easy Linux machine featuring an exposed n8n workflow automation platform (v1.65.0) vulnerable to a critical exploit chain comprising two CVEs: [CVE-2026-21858](https://nvd.nist.gov/vuln/detail/CVE-2026-21858) (Ni8mare) and [CVE-2025-68613](https://nvd.nist.gov/vuln/detail/CVE-2025-68613). The initial vulnerability stems from a `Content-Type confusion` bug in Form Webhook nodes that enables `arbitrary file reads` without authentication. By exploiting this flaw, we extract the `n8n` encryption key and `SQLite` database, forge a valid admin `JWT token`, and gain full administrative access. With authenticated access, we leverage the second CVE to bypass n8n's JavaScript sandbox and execute arbitrary system commands through Node.js `child_process`, ultimately obtaining a reverse shell as the n8n user and capturing the user flag.
