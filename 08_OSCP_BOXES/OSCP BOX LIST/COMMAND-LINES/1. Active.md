## Scan
```bash
nmap -sSCV 10.129.1.22 -oA Full_nmap -T4
```
**Expected:** Open ports: 53,88,135,139,389,445,464,593,636,3268,3269,49152-49165

---

## Enumerate SMB
```bash
smbmap -H 10.129.1.22
```
**Expected:** Replication share = READ ONLY

---

## Connect & Download Replication Share
```bash
smbclient //10.129.1.22/Replication -U ""%""
smb: \> recurse on
smb: \> prompt off
smb: \> cd active.htb
smb: \active.htb\> mget *
```
**Expected:** Downloads Policies, scripts, DfsrPrivate folders

```bash

```
