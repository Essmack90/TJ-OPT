### Practical Decoder Workflow

```
# Step 1: Find encoded string in request/response
# Step 2: Copy to Decoder
# Step 3: Click "Smart Decode" - Burp tries all common encodings
# Step 4: If that fails, try each encoding manually
# Step 5: For nested encoding, click "Add" to create new layer

```
